# Checklist — SEO y GEO

Usa esta lista para revisar una pagina.

## SEO on-page

- [ ] `<title>` unico y descriptivo
- [ ] Meta description clara (si aplica)
- [ ] Un `h1` alineado con el tema
- [ ] Headings en orden logico
- [ ] URL legible
- [ ] Enlaces internos con texto descriptivo
- [ ] Imagenes informativas con `alt` util

## Contenido

- [ ] Responde la intencion de busqueda principal
- [ ] La intro responde en pocas lineas
- [ ] Hay ejemplos o pasos concretos
- [ ] No hay relleno ni keyword stuffing
- [ ] Informacion sensible al tiempo tiene contexto/fecha si hace falta

## Tecnico basico

- [ ] La pagina es accesible por HTTPS
- [ ] Se ve usable en movil
- [ ] El texto importante esta en el HTML (no solo en imagen)
- [ ] No hay `noindex` accidental si quieres indexar
- [ ] Canonical coherente si hay URLs parecidas

## GEO

- [ ] Definiciones citables (1–2 frases)
- [ ] Secciones con headings que parecen preguntas o temas claros
- [ ] Listas / pasos / tablas donde aportan
- [ ] Afirmaciones concretas, no solo eslogans
- [ ] FAQ solo si responde dudas reales
- [ ] Consistente con otras paginas del mismo sitio

## HTML relacionado

- [ ] Estructura semantica razonable ([guia](../html/semantico/checklist.md))
