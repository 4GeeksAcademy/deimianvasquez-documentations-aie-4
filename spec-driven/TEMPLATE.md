# Template — Spec-driven

Usá esta plantilla para crear una spec nueva. Copiala y completá cada sección.

```markdown
# Nombre de la spec

## Problema

Qué se quiere resolver y por qué.

## Alcance

Qué entra y qué queda afuera.

## Requisitos

- Requisito 1
- Requisito 2

## Criterios de aceptación

- [ ] Criterio 1
- [ ] Criterio 2

## Fuera de alcance

Qué no cubre esta spec.
```
