# Template — Context

Usá esta plantilla para crear un context nuevo. Copiala y completá cada sección.

```markdown
# Nombre del context

## Propósito

Qué problema resuelve este context y para quién.

## Cuándo usarlo

Situaciones en las que aplica.

## Contenido

Instrucciones, reglas y contexto que el agente o la persona debe tener.

## Fuera de alcance

Qué no cubre este context.
```
